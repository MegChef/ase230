## Question 2.10

Explain why the `.env` file should never be committed to version control (Git/GitHub).

---

**Answer:**

- The file keeps sensitive or changing values outside of code. If it is committed to Github those values would be visible to public parties.

## Question 2.11

Compare the default SQLite database configuration with MySQL configuration in terms of setup complexity and use cases.

---

**Answer:**

- SQLite => Lightweight, zero-configuration, best for small or single-user projects.
**Setup Complexity**
Very simple there is no server installation required. The database is just a single file created automatically.
**Use Cases**
Ideal for local development, testing, small applications, or educational purposes.

- MySQL => Relational database suited for production and multi-user environments.
**Setup Complexity**
Requires installing and configuring a database server, creating users, setting passwords, and managing connections.
**Use Cases**
Production environments, large-scale apps, multi-user systems, and cloud deployments.
