## Question 1.5

According to the lecture, what happens when you run this Docker command?

```bash
docker run -it php:8.2-cli php --version
```

---

**Answer:**

- Pulls the php:8.2-cli image (if missing), starts a container, runs php --version, and prints the PHP version.

---

## Question 1.6

What does this Docker command do?
```bash
docker run --rm -v $(pwd):/app -w /app php:8.2-cli php test.php
```

---

**Answer:**

- Runs test.php using PHP inside a container, mounting the current directory into /app, then removes the container afterward.

---

## Question 1.10

What is a VPS and how does Docker help with VPS hosting costs?

---

**Answer:**

- A VPS is a virtual machine that runs on a physical server (A Virtual Private Server).
- Docker allows multiple lightweight containers on one VPS, reducing the need for multiple servers and lowering costs.

---

## Question 1.11

Why is Docker considered "lighter" than virtual machines?

---

**Answer:**

- Containers share the host OS kernel and do not run a full guest OS, making them much smaller and faster than VMs.

---

## Question 1.12

What does this Docker architecture represent?

```txt
Your Computer
├── Docker (any OS)
└── Containers
    ├── [Laravel Container] Ubuntu + PHP 8.2 + Code
    ├── [MySQL Container] MySQL 8.0 + Database
    └── [Nginx Container] Web server + Config
```

---

**Answer:**

- A multi-container application where each service (Laravel, MySQL, Nginx) runs in its own isolated container.
