# Q3. Docker with PHP and NGINX

---

## Question 3.1

What is the architecture setup for PHP and NGINX containers?

---

**Answer:**

- PHP runs in a PHP-FPM container, NGINX runs in a separate web server container, and both communicate over an internal Docker network.
- NGINX → PHP-FPM → PHP code → response.
- [Browser] → [NGINX Container] → [PHP Container] → [Your PHP App]
              Port 8080           Port 9000

---

## Question 3.2

What does `docker-compose.yml` do that single Docker commands cannot?

---

**Answer:**

- It defines and runs multiple containers together as one application—networking, volumes, environment variables, dependencies—something single Docker commands can't coordinate easily.

docker-compose.yml  lets you define:

- Services (nginx, php, db...)
- Networks (so containers talk to each other)
- Volumes (share code/data)
Run everything with one command:
- `docker compose up`

---

## Question 3.3

In the nginx configuration, what does `fastcgi_pass php-app:9000;` do?

---

**Answer:**

- It forwards PHP requests from NGINX to the PHP-FPM service running on port 9000.

---

## Question 3.4

What commands start and stop a Docker Compose setup?

---

**Answer:**

```bash
# Start containers
docker-compose up -d
# Stop containers
docker-compose down
```

## Question 3.5

Complete this Docker Compose service configuration for NGINX:

```yaml
nginx:
  image: nginx:alpine
  container_name: web-server
  ports:
    - "8080:80"
  volumes:
    - ./www:/var/www/html
    - ./nginx/default.conf:_______
  depends_on:
    - _______
```

---

**Answer:**

- `/etc/nginx/conf.d/default.conf`
- `php-app`

```yaml
services:
  # NGINX Web Server
  nginx:
    image: nginx:alpine
    container_name: web-server
    ports:
      - "8080:80"
    volumes:
      - ./www:/var/www/html
      - ./nginx/default.conf:/etc/nginx/conf.d/default.conf
    depends_on:
      - php-app
```

## Question 3.6

What is the difference between `php:8.2-cli` and `php:8.2-fpm` Docker images?

---

**Answer:**

- php:8.2-cli => runs PHP scripts from the command line (php file.php).

- php:8.2-fpm => runs PHP-FPM, required for NGINX to process PHP web pages.

---

## Question 3.7

In a PHP Dockerfile, what does this line accomplish?

```dockerfile
RUN chown -R www-data:www-data /var/www/html
```

---

**Answer:**

- It changes ownership of the application files to the www-data user/group so NGINX and PHP-FPM can read/write them correctly.

## Question 3.11

What is the purpose of the `depends_on` directive in Docker Compose?

---

**Answer:**

- Ensures one service starts after another (e.g., NGINX waits for PHP-FPM to start).

---

## Question 3.12

If you get a "502 Bad Gateway" error, what is the most likely cause and solution?

---

**Answer:**

Most likely PHP-FPM is not reachable at port 9000.

Fix:

- Ensure PHP-FPM container is running

- Ensure `fastcgi_pass php-app:9000` matches service name and port

---

## Question 3.13

What is the advantage of using volume mapping (`-v ./www:/var/www/html`) during development?

---

**Answer:**

- Changes to your code update instantly inside the container; no rebuild needed.
