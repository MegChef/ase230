# Q4. Containerizing Laravel with Docker

---

## Question 4.1

What does the `setup.sh` script do in one simple sentence?

---

**Answer:**

- It automatically creates a new Laravel project and builds all required Docker containers for it.

---

## Question 4.2

If you run `bash setup.sh myproject`, what will be the name of the Laravel directory created?

---

**Answer:**

- myproject

---

## Question 4.3

What command does the setup script use to create a Laravel project?

---

**Answer:**

- `composer create-project laravel/laravel`

---

## Question 4.4

What are the three main containers in the Laravel Docker setup?

---

**Answer:**

- PHP-FPM container
- Nginx container
- MySQL container

---

## Question 4.5

In the `.env.docker` file, what do these database settings tell Laravel?

```bash
DB_HOST=mysql
DB_DATABASE=laravel
DB_USERNAME=laravel
DB_PASSWORD=laravel_password
```

---

**Answer:**

- They tell Laravel to connect to the MySQL Docker container using the provided database name, username, and password.

---

## Question 4.6

What is the difference between Laravel app configuration (`.env.docker`) and Docker container configuration (`.env`)?

---

**Answer:**

`.env.docker` → Laravel’s internal configuration (app + DB settings).

Docker `.env` → Environment variables used by Docker Compose for building containers.

---

## Question 4.7

Complete this Docker Compose service configuration for MySQL:

```yaml
mysql:
  build: ./docker/mysql
  container_name: laravel-mysql
  environment:
    - MYSQL_ROOT_PASSWORD=${_______}
    - MYSQL_DATABASE=${_______}
    - MYSQL_USER=${_______}
    - MYSQL_PASSWORD=${_______}
```

---

**Answer:**

```yaml
MYSQL_ROOT_PASSWORD=${MYSQL_ROOT_PASSWORD}
MYSQL_DATABASE=${MYSQL_DATABASE}
MYSQL_USER=${MYSQL_USER}
MYSQL_PASSWORD=${MYSQL_PASSWORD}
```

## Question 4.8

What does this health check do in the MySQL service?

```yaml
healthcheck:
  test: ["CMD-SHELL", "mysqladmin ping -h 127.0.0.1 -u root -p$MYSQL_ROOT_PASSWORD --silent"]
```

---

**Answer:**

- It checks if the MySQL server is running and accepting connections.
- Like: Setting up a secure filing cabinet with specific locks and keys

## Question 4.9

What Composer shortcut commands are defined in the `composer.json` scripts?

---

**Answer:**

`composer app-install` → installs dependencies

`composer app-update` → updates dependencies

---

## Question 4.10

What is the difference between `php:8.2-cli` and `php:8.2-fpm` in the context of Laravel deployment?

---

**Answer:**

CLI → runs commands in terminal (artisan, composer, migrations).

FPM → processes web requests and works with Nginx.

---

## Question 4.11

Why does the setup script wait 15 seconds after starting containers?

---

**Answer:**

- To give MySQL time to fully start before running migrations.

---

## Question 4.12

What commands does the script run inside the PHP container after MySQL is ready?

---

**Answer:**

`composer install`

`php artisan key:generate`

`php artisan migrate`

---

## Question 4.13

How do you backup the MySQL database from the Docker container?

---

**Answer:**

```bash
docker exec laravel-mysql mysqldump -u root -pPASSWORD laravel > backup.sql
```

---

## Question 4.14

What is the difference between Development and Production Docker configurations?

---

**Answer:**

Development → volumes, auto-refresh, debug mode on.

Production → no volumes, optimized, caching enabled, smaller images.

---

## Question 4.15

Complete this file structure for Laravel Docker setup:

```txt
Laravel Docker Project/
├── .env.docker          # Laravel app settings
├── docker-compose.yml   # Container coordinator
├── composer.json        # PHP package manager
├── .env                # _______ settings
└── docker/             # Container recipes
    ├── php/
    │   ├── _______     # PHP container recipe
    │   └── php.ini     # PHP development settings
    ├── nginx/
    │   ├── _______     # Web server recipe  
    │   └── nginx.conf  # Web server settings
    └── mysql/
        ├── _______     # Database container recipe
        └── init.sql    # Database initialization
```

---

**Answer:**

```txt
Laravel Docker Project/
├── .env.docker
├── docker-compose.yml
├── composer.json
├── .env                # Docker environment settings
└── docker/
    ├── php/
    │   ├── Dockerfile  # PHP container recipe
    │   └── php.ini
    ├── nginx/
    │   ├── Dockerfile  # Web server recipe
    │   └── nginx.conf
    └── mysql/
        ├── Dockerfile  # Database container recipe
        └── init.sql
```
